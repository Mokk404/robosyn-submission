# Inference provenance and dependencies

The existing formal 100-video evaluation appears at `RoboSynChallenge/eval_result/manipulate_pipette/act/random/None/pretrained_model/2026-09-29_00-21-34/videos/`; it contains 57 success and 43 fail files. `scripts/eval_policy.py` builds this path from `policy_name`, and the experimental `act_policy/run_eval.py` only accepts `experiments.manipulate_pipette.act_policy`. Consequently, the generic `policy/act` adapter is the supported source-code identity for this package. The video directory does not itself include a checkpoint fingerprint, so historical checkpoint attribution remains an experiment-record assertion.

Static import chain: `deploy/eval.sh` → `deploy/run_eval.py` → package-local `submitted_act` → byte-identical `policy/act/deploy_policy.py` copy → LeRobot `ACTPolicy`. The package initializer adds a four-result official compatibility wrapper; the launcher selects the original three-result adapter only for the modified local evaluator. `run_eval.py` imports the chosen runtime's `scripts/eval_policy.py`. Task/random environment and success API remain provided by the main project. No recovery collector, training dataset, failure-matched checkpoint, or teacher module is imported by the submitted adapter.

The copied adapter calls `ACTPolicy.from_pretrained(checkpoint_path, ...)`, reads `observation.state/qvel/qf` and three RGB images, calls `model.select_action()`, maps only gripper `[6,13]` from policy `[0,1]` to environment low/high, then calls `env.step()`. The project's evaluator checks `info.success` or `is_task_success()` and handles termination/video recording. LeRobot owns normalization, unnormalization and the action queue; no second numerical normalization is done by the adapter.

Safety switches: the package-local launcher clears `ACT_PRESS_REFRESH_STEP`, `ACT_T300_RECOVERY_DIAGNOSTIC`, `ACT_T300_RECOVERY_DELTA_PATH`, trace/repro variables, and explicitly sets `debug_button_press=False`, `debug_trajectory=False`, `action_chunk_offset=0`, `n_action_steps=50`. The dormant debug-only simulator-state branch in the byte-identical adapter is not exercised. Do not turn it on in final inference.

Submission-only differences are the relocated import name, the packaged checkpoint path, the official four-result timing wrapper, and disabling the local evaluator's interval-event freezing. The copied ACT executor and checkpoint files are not edited. No simulator evaluation was launched to test the official-aligned entry; consumer-side official-runtime smoke and rollout checks remain required.
